ALMa v0.24.1

This patch keeps failed captures reviewable and stops cold Discovery refreshes
from silently dropping their Taste/branch retrieval family.

## Added

- **Failed Inbox captures can be reviewed.** Home now shows what failed, why it
  failed, and the original capture input. You can correct and retry it or archive
  it without erasing the audit record.

## Fixed

- **Discovery keeps all four retrieval lanes on a cold process.** Taste/branch
  no longer spends its deadline waiting for the shared preference profile, and
  its 20–30 frontier queries normalise each candidate once rather than repeating
  that work for every query.

- **The local-lane backstop is now 60 seconds.** Existing installs still on the
  old 30-second default migrate automatically; deliberate custom values remain
  untouched. A timed-out lane remains loud in Activity.

## Notes

No external network calls were added to lens refresh. Taste/branch still reads
only the offline frontier. Failed capture records remain local and can be
archived explicitly.
