ALMa v0.24.0

This release narrows ALMa to its core. Feed, Discovery (with learning), Authors
and Library are the product; the Signal Lab and the semantic partition it fed
have left the main line and are preserved on a branch. Plugins now ship
switched off and cannot reach a service until you turn them on.

## Changed

- **The Signal Lab is no longer part of this line.** The minigames, the fitted
  model, the evaluation replay, the four additive ranking heads and the Home
  band are gone, preserved complete on the `feature/signal-lab` branch.

  This was measured, not assumed. On a real library the Lab's heads at their
  shipped weights made ranking **worse**: kept-versus-rejected AUC fell by
  0.055 with a 95% interval of [-0.091, -0.022], and turning the heads up made
  it worse still (-0.099). Meanwhile the feature had received no answers in
  eight weeks. A head that costs ranking quality and receives no input is not
  earning its place in the scorer.

  **Your answers are kept.** The `signal_lab_rounds` table and its migrations
  are untouched; nothing reads them here, and nothing deletes them.

- **The semantic partition and its regions follow it out.** They were retained
  when the map left because learning read them — and the Signal Lab was that
  reader. With it gone they had no consumer, so the clustering job and the
  "Prepare learning groups" repair are removed rather than left running to feed
  nothing. Their tables stay on existing installs, and a merge or a purge still
  takes their rows with the paper.

- **Ranking versions advanced** to `discovery-v8` with feature snapshot v6. A
  score is immutable evidence of how it was computed, so scores written before
  this release are not comparable with scores written after it; the next lens
  refresh rescores what it touches.

## Added

- **Plugins ship switched off and are provably inert until enabled.** A
  connectivity test on a switched-off plugin now returns 409 instead of really
  posting a message or sending mail; a newly shipped plugin defaults to off
  rather than failing; and the activation check lives in the primitive rather
  than in each caller.

## Fixed

- **The development server stopped requesting a renderer that left with the
  map.** A stale build-config entry named a package removed in an earlier
  release, so every dev-server start printed a dependency resolution error for
  something nothing imports.

- **Two background-maintenance tests had stopped testing anything.** A second
  admission gate added for scheduled network work silently disabled their
  positive controls, so they reported failures that named no cause. Both gates
  are now opened through one shared test fixture.

## Notes

Nothing here changes your data. The one behavioural change a reader will notice
is that Discovery and Feed scores no longer carry a Signal Lab contribution,
and the Home band and Settings card for it are gone.
