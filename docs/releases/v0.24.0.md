ALMa v0.24.0

This release adds PDFs — finding, fetching, reading and attaching them — and
narrows the core to Feed, Discovery (with learning), Authors and Library.
Plugins ship switched off and reach nothing until you turn them on.

## Added

- **PDFs, end to end.** Attach an upload, import PDF-first, open a paper's PDF
  from Library, Feed and Discovery, and hand off to your phone. Files live in a
  readable store; a paper's PDF state has one owner.

- **PDF sources are plugins, and they are opt-in.** `open_access` covers the
  legal sources. `shadow_libraries` (Sci-Hub, Anna's Archive) ships **off** and
  stays off until you switch it on, with member login supported and a real-path
  test per address.

- **Everything fetched is treated as hostile.** One gate for addresses and text
  from sites we do not control: vetted, pinned and redirect-checked HTTP
  clients, PDFs parsed in a sandbox with active content stripped, bot walls told
  apart from pages that merely mention one, and a peer that trickles bytes
  cannot outlive its deadline.

- **Plugins ship switched off and are provably inert.** A connectivity test on a
  switched-off plugin returns 409 instead of really posting a message or sending
  mail, and a newly shipped plugin defaults to off rather than failing.

## Changed

- **The Signal Lab is no longer part of this line**, preserved complete on the
  `feature/signal-lab` branch. It was measured, not assumed: its ranking heads
  at their shipped weights made ranking **worse** — kept-versus-rejected AUC
  fell 0.055, 95% interval [-0.091, -0.022], and turning them up made it worse
  still. It had also received no answers in eight weeks. **Your answered rounds
  are kept**; nothing reads them, nothing deletes them.

- **The semantic partition and its regions follow it out.** They were retained
  when the map left because learning read them, and the Signal Lab was that
  reader. No clustering job now runs for a consumer that no longer exists.

- **Ranking versions advanced** to `discovery-v8` with feature snapshot v6.
  Scores written before this release are not comparable with scores after it;
  the next lens refresh rescores what it touches.

## Fixed

- The development server stopped requesting a graph renderer that left with the
  map, an error it printed on every start.
- Two background-maintenance tests had silently stopped testing anything after a
  second network-admission gate was added.
- Test isolation covered only one of two HTTP transports, so shadow-library
  tests were making real outbound calls.

## Notes

Nothing here changes your data. Discovery and Feed scores no longer carry a
Signal Lab contribution, and its Home band and Settings card are gone.
